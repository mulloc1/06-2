# 평가 문항 10 · 파라미터 옵션화

## 답변

파라미터를 CLI 옵션으로 제공하는 이유는 세 가지다.

1. 모델·`temperature`·`max_tokens`를 명시해 비교 실험의 실행 조건을 재현한다.
2. 코드 수정 없이 모델별 품질과 출력의 일관성·다양성·길이·비용을 비교한다.
3. 커밋과 PR에 서로 다른 토큰 예산을 적용하고, 자동화 스크립트에서 설정을 명시적으로 덮어쓴다.

합리적인 기본값은 일반 사용의 복잡도를 낮추고, 명시적인 옵션은 실험과 운영 조정을 가능하게 한다. 입력 범위는 `argparse` 단계에서 검증해 잘못된 요청이 API까지 전달되지 않게 한다.
