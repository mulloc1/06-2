# 평가 문항 11 · API 예외 처리

## 답변

`ai_client.py`는 실패를 다음처럼 구분한다.

| 상황 | 사용자 안내 |
| --- | --- |
| 키 누락 | `CODYSSEY_API_KEY` 또는 `.env` 설정 안내 |
| HTTP 401 | 인증 실패 |
| HTTP 429 | 사용량·할당량 초과 |
| 기타 HTTP | 상태 코드와 안전한 원인 |
| 연결 실패 | 네트워크 연결 실패 원인 |
| 제한 시간 초과 | 설정된 timeout 초 포함 |
| 잘못된 JSON/스키마 | 생성 텍스트를 찾을 수 없음 |

키 누락은 HTTP 요청 전의 설정 오류로 처리하고, HTTP 오류는 상태 코드와 서버가 제공한 원인을 함께 알린다. 네트워크 연결 실패와 timeout은 다른 메시지로 구분한다. 내부에서는 이를 `APIError`로 통일해 CLI가 stderr에 출력하고 종료 코드 `1`을 반환하게 한다. 오류 상세는 300자로 제한하며 API 키와 인증 헤더는 노출하지 않는다.
