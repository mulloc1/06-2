# 기준 11 · API 예외 처리

`ai_client.py`는 실패를 다음처럼 구분한다.

| 상황 | 사용자 안내 |
| --- | --- |
| 키 누락 | `CODYSSEY_API_KEY` 또는 `.env` 설정 안내 |
| HTTP 401 | 인증 실패 |
| HTTP 429 | 사용량·할당량 초과 |
| 기타 HTTP | 상태 코드와 안전한 원인 |
| 연결 실패 | 네트워크 연결 실패 원인 |
| 제한 시간 초과 | 적용 시간 포함 |
| 잘못된 JSON/스키마 | 생성 텍스트를 찾을 수 없음 |

내부적으로는 단일 `APIError`를 사용하되 메시지로 원인을 구분하며 실행 오류는 종료 코드 1이다. 오류 본문은 300자로 제한하고 키를 노출하지 않는다.
