# 평가 문항 12 · temperature

## 답변

`temperature`는 생성 시 다음 토큰 선택의 무작위성을 조절한다. 낮으면 가능성이 높은 표현을 선택하는 경향이 커져 같은 입력에서 결과가 비교적 일관되고 형식을 지키기 쉬워진다. 높으면 표현이 다양해지지만 결과 편차, 과장, 형식 이탈 위험도 커진다.

커밋과 PR은 창의성보다 사실성·형식 준수·재현성이 중요하므로 기본값을 `0.2`로 낮게 둔다. 형식 오류로 재생성할 때는 사용자가 지정한 값을 절반으로 낮춰 안정성을 높인다. 여러 표현 후보나 아이디어를 탐색할 때는 더 높일 수 있지만, 낮은 값이 완전히 동일한 결과를 보장하는 것은 아니다.
