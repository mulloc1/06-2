# 평가 문항 16 · AI 한계와 수동 검토

## 답변

모델은 제공된 status와 diff만으로 실제 업무 동기, 전체 저장소 맥락, 테스트 성공 여부를 확정할 수 없다. 따라서 변경 이유를 잘못 추론하거나, 영향 범위를 과장하거나, 실행하지 않은 테스트를 통과했다고 쓰는 오류가 생길 수 있다. 학습 데이터나 프롬프트 표현에 따른 편향과 팀 문체 불일치도 가능하다.

도구는 이러한 한계를 전제로 결과를 `AI ... 초안`으로 표시하고 실제 commit·push·PR 생성을 수행하지 않는다. 사용자는 실제 diff, 변경 의도, 직접 실행한 테스트 결과와 초안을 대조해 사실성과 누락을 확인한 뒤 수정해야 한다. 또한 diff가 외부 API로 전송되므로 실행 전에 비밀키, 개인정보, 내부 URL이 포함되지 않았는지 검토해야 한다.
