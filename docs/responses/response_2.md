# 평가 문항 2 · PR 초안 생성

## 답변

`pr` 명령은 한 줄의 `TITLE`과 `Why`, `What`, `How to Test` 섹션으로 구성된 PR 본문을 생성한다. 제목 길이와 필수 섹션을 검증한 후 `=== AI PR 초안 ===` 헤더와 함께 표준출력에 보여준다.

`초안`이라는 표현과 마지막 검토 안내를 통해 이 결과가 바로 게시할 완성본이 아님을 명확히 한다. 도구는 GitHub PR을 직접 생성하지 않으며, 사용자가 사실관계와 테스트 절차를 확인한 뒤 복사해 사용한다.

```bash
python3 -m ai_git_cli pr
```
