# 평가 문항 5 · PR 본문 구조

## 답변

`prompts.build_messages("pr", ...)`는 PR 제목과 본문을 다음 형식으로만 생성하도록 모델에 요구한다.

```text
TITLE: <최대 80자>
## Why
- ...
## What
- ...
## How to Test
- ...
```

`Why`는 변경의 필요성, `What`은 핵심 변경 내용, `How to Test`는 검증 방법을 담는다. `validators.validate()`는 세 헤더가 있고 각 섹션에 `- ` 또는 `* `로 시작하는 불릿이 최소 하나씩 있는지 검증한다. 누락되면 위반 이유를 전달해 한 번 재생성하고, 두 번째 결과도 잘못되면 임의의 내용을 채우지 않고 오류로 종료한다.
