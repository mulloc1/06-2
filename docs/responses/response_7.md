# 평가 문항 7 · 출력 포맷 규칙

## 답변

커밋 프롬프트는 `SUBJECT` 한 줄을 50자 이하로 권장하고 72자를 최대치로 지정하며, `BODY`에 1~2개의 핵심 변경 불릿을 요구한다. PR은 `TITLE` 80자 이하와 `Why`, `What`, `How to Test` 섹션별 최소 한 개의 불릿을 요구한다.

규칙은 `prompts.py`에서 먼저 지시하고 `validators.py`에서 결과를 다시 검증한다. 다만 **50자는 권장사항**이므로 51~72자의 커밋 제목도 검증을 통과하고, 73자부터 오류로 판정한다. 테스트는 커밋 50/51/72/73자, PR 80/81자 경계와 불릿·섹션 누락을 확인한다.
