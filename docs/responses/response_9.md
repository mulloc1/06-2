# 평가 문항 9 · 프롬프트와 출력 후처리

## 답변

프롬프트는 Git 변경 맥락, 출력 템플릿, 길이·불릿 규칙, 허위 내용 금지를 모델에 전달해 원하는 결과를 처음부터 생성하게 한다. 반면 출력 후처리의 검증기는 제목 길이, 필수 헤더, 불릿 수처럼 코드로 판정할 수 있는 규칙만 담당한다.

생성과 검증을 분리하면 프롬프트만으로 형식 준수를 가정하지 않으면서도, 검증기가 AI의 의미를 임의로 바꾸는 문제를 피할 수 있다. 형식이 틀리면 위반 이유를 제공해 한 번 재생성하고, 유효한 결과는 재조립하지 않고 원문 그대로 출력한다.
